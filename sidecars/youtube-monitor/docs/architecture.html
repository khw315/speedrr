Architecture & Data Flow

YouTube Network Traffic Monitor Sidecar

Real-time passive packet sniffing, TLS SNI extraction, and dynamic webhook throttling for Speedrr.

PACKET CAPTURE

Subnet BPF & Zero-Alloc SNI

  • Linux kernel BPF filter supports single IPs (host) and full CIDR subnets (net 192.168.1.0/24).
  • Byte-offset TLS Client Hello parser extracts domain names without regexp memory allocations.

STABILITY

Multi-Client Tracking

  • Per-client timer tracking manages independent cooldowns across the whole subnet.
  • Aggregates active client count (active_stream_count) and list in real time.

SPEEDRR INTEGRATION

Automated Enforcement

  • Asynchronous JSON webhook dispatches instantly on stream start, update, and stop events.
  • Allows Speedrr to dynamically scale bandwidth based on exact active stream count.
